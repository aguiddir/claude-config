# GitHub signature

Applies whenever you write something on GitHub on my behalf: pull request
(title excluded), PR or issue comment, review and review comment, issue,
discussion, release notes, via `gh`, the API or an MCP tool.

End the text with a blank line then `🤖 Claude pour aguiddir` on its own line,
so a reader knows an agent wrote it, not me. It is the very last line.

Commit messages are git, not GitHub: they don't get this signature.
